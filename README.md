## 装飾変更について  
このプロジェクトでは`Node.js`の**v18**以上が必要です。
`package.json`の`scripts`に`start`コマンドを追加してください。
以前は~yarn~を使っていましたが、現在は`npm`を推奨しています。
`npm run dev`で開発サーバーが起動します。
